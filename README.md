# Rubik Lab — Cubo 3×3

Aplicación web interactiva para practicar con un cubo de Rubik 3×3.

## Funciones
- Vista 3D que puedes orbitar con el mouse o con el dedo.
- Giros U, D, R, L, F y B, con movimientos inversos y dobles.
- Mezcla aleatoria de 22 movimientos.
- Deshacer y rehacer movimientos.
- Reinicio del cubo y atajos de teclado.
- Contador de movimientos y estado del cubo.

## Ejecutar
Abre `index.html` desde un servidor web estático. La aplicación carga Three.js y OrbitControls desde jsDelivr, así que necesita conexión a internet.

## Publicar con GitHub Pages
1. En GitHub, abre **Settings → Pages**.
2. En **Build and deployment**, selecciona **Deploy from a branch**.
3. Selecciona la rama **main** y la carpeta **/ (root)**.
4. Guarda los cambios. GitHub mostrará la dirección pública de la página en esa misma sección.
